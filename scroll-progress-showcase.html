스크롤 프로그레스 인디케이터

6가지 다양한 스타일의 스크롤 프로그레스 인디케이터를 UijeongBoo 디자인 시스템으로 구현했습니다. 순수 CSS와 최소한의 JavaScript로 최적의 성능을 제공합니다.

/* CSS-Only 프로그레스 바 */ .top-progress-bar { animation: topProgressAnimation linear; animation-timeline: scroll(root); animation-range: 0% 100%; } @keyframes topProgressAnimation { from { transform: scaleX(0); width: 0; } to { transform: scaleX(1); width: 100vw; } }

구현 기술

이 쇼케이스는 최신 CSS Scroll-driven Animations API를 활용하여 JavaScript 의존성을 최소화하면서도 부드러운 스크롤 애니메이션을 제공합니다.

상단의 그라데이션 프로그레스 바와 사이드 수직 프로그레스는 완전히 CSS만으로 구현되었으며, 원형 프로그레스와 파티클 효과는 최소한의 JavaScript로 보완했습니다.

모든 인디케이터는 UijeongBoo 디자인 원칙을 준수합니다: 라임 그린 포인트 컬러, 투명 배경, 그레이스케일 팔레트를 사용했습니다.

성능 최적화

모든 애니메이션은 GPU 가속을 활용하여 부드러운 60fps 성능을 보장합니다. will-change 속성과 transform3d를 사용하여 하드웨어 가속을 적용했습니다.

스크롤 이벤트는 requestAnimationFrame으로 쓰로틀링하여 과도한 계산을 방지하고 배터리 수명을 보호합니다.

// 성능 최적화된 스크롤 핸들러 let ticking = false; function updateProgress() { const scrollProgress = window.pageYOffset / (document.documentElement.scrollHeight - window.innerHeight); // 프로그레스 업데이트 로직 } window.addEventListener('scroll', () => { if (!ticking) { requestAnimationFrame(() => { updateProgress(); ticking = false; }); ticking = true; } });

브라우저 호환성

CSS Scroll-driven Animations는 Chrome 115+, Firefox 114+에서 지원됩니다. 지원하지 않는 브라우저에서는 JavaScript 폴백으로 동일한 경험을 제공합니다.

@supports 규칙을 사용하여 기능 감지를 수행하고, 각 브라우저에 최적화된 구현을 제공합니다.

접근성 고려사항

prefers-reduced-motion 미디어 쿼리를 지원하여 운동 감수성이 있는 사용자를 위해 애니메이션을 비활성화할 수 있습니다.

모든 프로그레스 인디케이터는 의미적으로 진행률을 나타내며, 스크린 리더 사용자도 페이지 진행 상황을 이해할 수 있도록 구성했습니다.

모바일 최적화

터치 스크롤링에 최적화되어 iOS Safari와 Android Chrome에서 부드러운 스크롤 경험을 제공합니다.

작은 화면에서도 방해가 되지 않도록 크기를 조절하고, 터치 영역을 고려한 반응형 디자인을 적용했습니다.

사용자 경험

각 프로그레스 인디케이터는 다른 정보를 제공합니다: 상단 바는 전체 진행률, 원형은 정확한 퍼센티지, 사이드 바는 시각적 가이드, 파티클은 단계별 진행, 읽기 프로그레스는 예상 시간, 3D 큐브는 재미있는 시각적 요소를 담당합니다.

이러한 다양한 접근 방식을 통해 사용자는 자신의 스크롤 위치와 남은 콘텐츠를 직관적으로 파악할 수 있습니다.

결론

스크롤 프로그레스 인디케이터는 단순해 보이지만, 사용자 경험에 큰 영향을 미치는 중요한 UI 요소입니다.

UijeongBoo 디자인 시스템의 원칙을 지키면서도 다양한 스타일과 기능을 제공하여, 어떤 프로젝트에도 적용할 수 있는 유연성을 확보했습니다.

현대적인 CSS 기능과 최소한의 JavaScript로 최적의 성능과 사용자 경험을 동시에 달성했습니다.
