웹플로우 사용 가이드

1. 컬러 팔레트 복사하기

위의 코드를 복사한 후 웹플로우 프로젝트의 Custom Code 섹션에 붙여넣으세요.

2. 글로벌 스와치 생성하기

웹플로우에서 각 색상을 글로벌 스와치로 등록하여 프로젝트 전체에서 일관되게 사용하세요.

3. 클래스 적용하기

생성된 CSS 클래스를 요소에 적용하여 배경색, 텍스트 색상, 테두리 색상을 설정하세요.
