주요 특징

미니멀 디자인

불필요한 그림자와 장식 없이 순수한 플랫 디자인. 그레이스케일 팔레트와 라임 그린 포인트.

완벽한 컴포넌트

버튼, 카드, 폼, 네비게이션, 애니메이션 등 즉시 사용 가능한 검증된 컴포넌트.

텍스트 오버플로우 자동 처리

모든 텍스트 요소에 ellipsis 자동 적용. UI 깨짐 방지.

전역 강제 시스템

개별 컴포넌트의 실수를 자동으로 교정하는 전역 CSS 강제 적용.

물 차오르는 효과

텍스트 전용 물 차오르기 그라데이션 애니메이션. 배경 간섭 없음.

검증 도구 내장

디자인 규칙 준수 여부를 자동으로 검증하는 스크립트 포함.
