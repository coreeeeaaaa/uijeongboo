2. 아코디언 (CSS Only)

JavaScript 없이 체크박스와 CSS만으로 구현한 아코디언

UijeongBoo는 라임 그린(#32CD32)과 그레이스케일만을 사용하는 엄격한 디자인 시스템입니다. 모든 UI 요소는 투명 배경과 플랫 디자인을 기본으로 하며, 그림자나 글로우 효과는 절대 사용하지 않습니다.

  • • 라임 그린 외 모든 색상 금지
  • • 투명 버튼 배경 강제
  • • Box-shadow 속성 금지
  • • 이모지 사용 금지

모든 인터랙티브 요소는 JavaScript 없이 순수 CSS만으로 구현됩니다. 체크박스의 :checked 상태, 라디오 버튼의 상태 변화, :hover 효과를 활용하여 복잡한 UI 동작을 만들어냅니다.

  • • :checked 가상 클래스 활용
  • • CSS 형제 선택자(+ ~) 사용
  • • transform과 transition 조합
  • • keyframes 애니메이션

햄버거 메뉴 10개, 검색 아이콘 10개, 로그인 아이콘 10개, 결제 아이콘 10개, 저장 아이콘 10개, 다운로드 아이콘 10개, 업로드 아이콘 10개 등 총 70개의 CSS-only 아이콘 애니메이션을 제공합니다.

  • • 70개 인터랙티브 아이콘
  • • 순수 CSS 애니메이션
  • • 가벼운 브라우저 성능
  • • 모바일 반응형 지원

모든 컴포넌트는 데스크톱부터 모바일까지 완벽하게 대응하는 반응형 디자인을 적용했습니다. CSS Grid와 Flexbox를 활용하여 다양한 화면 크기에서 최적의 사용자 경험을 제공합니다.

  • • CSS Grid 기반 레이아웃
  • • 모바일 터치 친화적
  • • 유연한 아이콘 크기 조정
  • • 768px 브레이크포인트 최적화

모든 애니메이션은 GPU 가속을 활용하는 transform 속성을 사용하여 부드러운 60fps 성능을 보장합니다. 불필요한 reflow와 repaint를 최소화하여 브라우저 성능을 최적화했습니다.

  • • GPU 가속 transform 사용
  • • 최적화된 transition timing
  • • 메모리 효율적 구조
  • • 60fps 부드러운 애니메이션
