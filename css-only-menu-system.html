Projects

진행 중인 프로젝트들을 관리하고 추적할 수 있습니다.

UijeongBoo Framework
최소한의 JavaScript를 사용하는 CSS 중심의 디자인 프레임워크 개발 프로젝트입니다. HTML/CSS만으로 대부분의 인터랙션을 구현하는 것이 목표입니다.
Component Library
재사용 가능한 UI 컴포넌트 라이브러리를 구축하고 있습니다. 모든 컴포넌트는 UijeongBoo 디자인 규칙을 준수합니다.
Documentation Site
개발자들을 위한 포괄적인 문서화 사이트를 제작하고 있습니다. 사용법, 예제, 가이드라인을 포함합니다.

Components

UijeongBoo 프레임워크의 모든 컴포넌트를 확인하고 테스트할 수 있습니다.

CSS-Only Menu
현재 보고 계신 메뉴 시스템입니다. JavaScript 없이 순수 CSS만으로 구현되었습니다. 라디오 버튼과 CSS 선택자를 활용했습니다.
Interactive Cards
호버 효과와 애니메이션이 적용된 카드 컴포넌트입니다. 텍스트 오버플로우 처리와 반응형 디자인을 지원합니다.
CSS Sidebar
체크박스와 CSS 선택자를 활용한 사이드바 시스템입니다. JavaScript 없이도 완전한 네비게이션 기능을 제공합니다.

Chat System

실시간 채팅 인터페이스입니다. 이 기능은 JavaScript가 필요한 예외적인 경우입니다.

실시간 메시징
WebSocket이나 Server-Sent Events를 사용한 실시간 통신은 JavaScript가 필수적인 영역입니다. 하지만 UI는 CSS로 최대한 구현합니다.
메시지 인터페이스
채팅 버블, 입력창, 상태 표시 등 UI 요소들은 CSS로 스타일링하고, 메시지 전송과 수신만 JavaScript로 처리합니다.
파일 업로드
드래그 앤 드롭, 파일 선택 UI는 CSS로 구현하고, 실제 업로드 로직만 JavaScript로 처리하는 것이 UijeongBoo 방식입니다.

Settings

시스템 설정과 개인화 옵션을 관리할 수 있습니다.

테마 설정
UijeongBoo 프레임워크는 라임 그린 액센트와 그레이스케일 팔레트를 사용합니다. 커스터마이징은 CSS 변수를 통해 제한적으로 가능합니다.
레이아웃 옵션
사이드바 위치, 메뉴 스타일, 카드 레이아웃 등을 설정할 수 있습니다. 모든 변경사항은 CSS 클래스 전환으로 처리됩니다.
접근성 설정
키보드 네비게이션, 포커스 표시, 색상 대비 등 접근성 관련 설정을 관리할 수 있습니다. CSS로 대부분 구현 가능합니다.
